Alertas

O que precisa de atenção: clientes parados ou esfriando, quedas de uso, pessoas que nunca entraram e problemas nos dados. Adie um alerta quando já estiver cuidando dele.

Mensagens

Conversas dos usuários com a equipe. Qualquer administrador pode responder; o usuário vê o nome de quem respondeu. Cada mensagem mostra o relatório (e a fazenda do CCV) que a pessoa estava vendo.

Alertas CCV

Situação da última semana de leitura de cocho em cada fazenda ligada a um cliente, comparada à semana anterior. Para cada fazenda, decida: enviar o alerta, enviar o resumo da semana, adiar ou dar por tratado. Tudo fica registrado no histórico.

Uso do portal

Como os clientes usam o portal: os relatórios do Power BI (acessos, tempo, PDFs e perguntas ao assistente) e, na outra sub-aba, as ferramentas (4M e 3P) por usuário. Acessos de administradores (inclusive "entrar como") não entram na conta.

Saúde dos dados

De quando são os dados de cada relatório liberado e se a atualização no Power BI está funcionando. A verificação roda sozinha a cada 6 horas.

Relatórios

Relatórios do Power BI disponíveis no portal. Use a configuração automática para cadastrar relatórios e clientes de uma vez.

Clientes

Cada cliente é uma empresa. Escolha quais relatórios ela vê e, se o relatório usar RLS, qual filtro de dados se aplica a ela.

Usuários

Pessoas que fazem login no portal. Cada usuário de cliente vê os relatórios liberados para a empresa dele.

Categorias

Cada categoria tem nome, descrição e imagem. Os relatórios da categoria herdam a descrição e a imagem, a menos que tenham as suas (em Relatórios → Editar). Mudanças aqui valem na hora para todos os relatórios da categoria.

Imagens dos relatórios

Biblioteca de imagens usadas nas categorias e nos relatórios. Use formato paisagem (16:9), como 1280 × 720, em PNG, JPG ou WEBP, até 5 MB. Para escolher a imagem de uma categoria, vá à aba Categorias.

Arraste imagens para cá ou use o botão "Enviar imagens".

Benchmarking Confinamento

Andamento da coleta de cada cliente participante (marque "Participa do Benchmarking" no cadastro do cliente). Abra a coleta para revisar os alertas, devolver para correção ou aprovar. Os limites de validação valem para todas as fazendas.

Cotações

A faixa que roda no rodapé do portal. Os preços brasileiros (indicadores do CEPEA, por exemplo) são lançados aqui uma vez por dia; a tendência é calculada contra o lançamento anterior. Câmbio e bolsas de Chicago atualizam sozinhos.

Assistente no WhatsApp

Os clientes recebem relatórios em PDF, redefinem a senha e fazem perguntas sobre os dados pelo WhatsApp. O bot reconhece cada pessoa pelo telefone cadastrado no usuário. Use o simulador para testar como um cliente.
